# ReelXP

A personal film & TV tracker: tick off films and episodes, rate in half stars, keep a watchlist, work through The Greats, and level up.

Powered by [TMDB](https://www.themoviedb.org/). This product uses the TMDB API but is not endorsed or certified by TMDB.

## Setup
1. Host these files with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
2. Open the site, paste your free TMDb API key (themoviedb.org → Settings → API) when asked.
3. Add it to your phone's home screen.

Your key and your library are stored only in your browser. Use Settings → Download backup regularly.
